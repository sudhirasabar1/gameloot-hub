# GameLootHub

A responsive static gaming discovery website designed for GitHub Pages.

## Pages
- `index.html` — homepage
- `rewards.html` — gaming rewards/promotions page
- `games.html` — game discovery
- `guides.html` — gaming guides
- `style.css` — responsive design
- `script.js` — navigation and offer placeholders

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and wait for the GitHub Pages URL.

## Add your CPA offer
Open `script.js` and replace the placeholder action with your approved AdBlueMedia offer URL or approved integration.

Do not advertise rewards that you cannot actually provide. Keep the offer wording, eligibility, device requirements and completion steps consistent with the actual offer terms.
